# 더 메이커 브라우저 도구 — 디자인 기준

`snap-box` 와 `clip-box` 는 자매 도구다. 두 개를 나란히 열었을 때 **같은 제품**으로
보여야 한다. 이 문서는 그 기준이고, 앞으로 만드는 도구도 여기에 맞춘다.

기준의 원본은 **snap-box** 다. `css/base.css` 는 snap-box 의 `css/style.css` 에서
도구에 안 매인 부분만 값 그대로 뽑아낸 것이다.

---

## 0. 한 줄 원칙

> **껍데기는 똑같이, 속은 도구답게.**
> 토큰·부품·레이아웃 골격은 공유하고, 도구 고유의 화면만 각자 만든다.

---

## 1. 파일 나누기

```
css/
  base.css     ← 공용. 자매 도구끼리 내용이 같아야 한다.
  style.css    ← 이 도구만의 것. base.css 뒤에 불러온다.
```

`index.html`:

```html
<link rel="stylesheet" href="css/base.css">
<link rel="stylesheet" href="css/style.css">
```

**base.css 를 도구 하나 때문에 고치지 않는다.** 새 부품이 필요하면

1. 먼저 그 도구의 `style.css` 에서 만들어 쓴다.
2. 두 번째 도구가 같은 것을 원하면, 그때 `base.css` 로 올리고 두 도구 모두에 반영한다.

## 2. 색 — 토큰 말고는 쓰지 않는다

```css
--bg:#12151b      /* 화면 바닥 */
--pane:#1a1f28    /* 패널(좌·우·상·하 바) */
--pane2:#222834   /* 패널 안의 상자 (.grp, 목록 항목) */
--line:#2d3543    /* 모든 경계선 */
--fg:#e6ebf2      /* 본문 글자 */
--dim:#8c98ab     /* 보조 글자 — 라벨, 힌트, 단위 */
--accent:#2f6feb  /* 파랑 — 선택됨 / 지금 하는 일 / primary 버튼 */
--accent2:#3fb950 /* 초록 — 다 됨 / 일괄 실행(accent 버튼) */
--warn:#d29922    /* 노랑 — 진행 중 / 주의 */
--danger:#f0533f  /* 빨강 — 실패 / 지우기 */
--radius:8px
```

- CSS 파일 어디에도 **새 색상 리터럴을 적지 않는다.** (base.css 안에 이미 굳어 있는
  `#2a3140`, `#141922` 같은 버튼·입력칸 바탕만 예외이고, 그것도 base.css 안에만 있다.)
- 다크 테마 하나만 쓴다. 라이트 모드는 없다.
- 상태색은 뜻이 고정이다. 초록을 "선택됨" 에 쓰거나 파랑을 "완료" 에 쓰지 않는다.

| 뜻 | 색 | 쓰는 곳 |
|---|---|---|
| 선택됨 · 진행 중 | `--accent` | 탭 밑줄, 활성 목록 테두리, 진행률 바, primary 버튼 |
| 다 됨 | `--accent2` | 완료 상태 글자, 일괄 실행 버튼, 성공 토스트 |
| 하는 중 · 주의 | `--warn` | 처리 중 상태 글자, 경고 토스트 |
| 실패 · 지우기 | `--danger` | 오류 테두리·글자, 오류 토스트 |

## 3. 글자

```css
font:13px/1.5 "Pretendard","Apple SD Gothic Neo","Malgun Gothic",system-ui,sans-serif;
word-break:keep-all;
```

- **웹폰트를 동봉하지 않는다.** 시스템에 Pretendard 가 있으면 쓰고, 없으면 기본 한글
  글꼴로 떨어진다. 도구 하나 열자고 몇 MB 를 받게 하지 않는다.
- `word-break:keep-all` 은 필수다. 없으면 한글이 어절 중간에서 끊긴다.
- 크기는 셋뿐이다: 본문 `13px`, 보조 `12px`, 잔글씨 `11px`. 그 사이 값을 새로 만들지 않는다.
- 숫자가 바뀌며 표시되는 곳(시간, 용량, 좌표)은 `.num` 또는
  `font-variant-numeric:tabular-nums` 로 자릿수를 고정한다.

### 아이콘 폰트를 쓰지 않는다

Font Awesome 같은 아이콘 폰트를 넣지 않는다. 버튼은 **글자 라벨**로 쓴다.
꼭 기호가 필요하면 `←` `→` `×` `▶` 같은 문자나 인라인 SVG 를 쓴다.
파비콘도 파일 대신 인라인 SVG data URI 로 둔다.

이유: 라벨이 한국어라 아이콘보다 읽기 쉽고, 받을 파일이 줄고, 번역이 쉽다.

## 4. 레이아웃 골격

```
┌──────────────────────────────────────────────────────┐
│ #topbar   46px   브랜드 · 태그라인 ····· 개인정보 안내 │
├──────────┬──────────────────────────┬────────────────┤
│#queuePane│      #stagePane          │   #toolPane    │
│  210px   │        1fr               │     310px      │
│          │  #stageHead (한 줄 정보)  │  #tabs (4칸)   │
│ 드롭존    │  #stageWrap  (본 화면)    │  .tabbody      │
│ 목록      │                          │   .grp         │
│ .pane-foot│                          │    .grp-title  │
│          │                          │    .row        │
│          │                          │    .hint       │
├──────────┴──────────────────────────┴────────────────┤
│ #bottombar 50px  이동 · 실행 ······· 진행률            │
└──────────────────────────────────────────────────────┘
```

역할이 고정돼 있다. 도구가 달라도 자리를 바꾸지 않는다.

| 자리 | 하는 일 |
|---|---|
| `#topbar` | 도구 이름, 한 줄 설명, "밖으로 안 나갑니다" 안내 |
| `#queuePane` | **입력** — 드롭존 + 지금 다룰 것들의 목록 |
| `#stagePane` | **지금 보는 것 하나** — 위에 한 줄 정보(`#stageHead`) |
| `#toolPane` | **설정** — 탭 4개, 각 탭 안은 `.grp` 상자들 |
| `#bottombar` | **동사** — 실행 버튼과 진행률. 설정은 여기 두지 않는다 |

- 탭은 **4개로 고정**이다 (`grid-template-columns:repeat(4,1fr)`). 더 필요하면 묶어서 줄인다.
- 실행 버튼은 오른쪽 패널이 아니라 **아래 바**에 둔다. 탭을 옮겨도 늘 같은 자리에 있어야 한다.
- 폭은 토큰(`--w-queue`, `--w-tool`)으로만 바꾼다. 도구 사정으로 바꿨으면 `style.css`
  맨 위에 **왜 바꿨는지 주석을 남긴다.**
- 데스크톱 전용이다. `<meta name="viewport" content="width=1280">`. 모바일 대응은 하지 않는다.

## 5. 부품

### 버튼 `.btn`

| 클래스 | 뜻 | 화면에 몇 개 |
|---|---|---|
| `.btn` | 보통 동작 | 제한 없음 |
| `.btn.primary` | 그 화면의 주 동작 | 패널마다 **1개** |
| `.btn.accent` | 일괄/전체 실행 (초록) | 화면 전체에 **1개** |
| `.btn.danger` | 되돌릴 수 없는 것 (빨강) | 꼭 필요할 때만 |
| `.btn.ghost` | 보조·취소 | 제한 없음 |
| `.btn.tiny` | `.pane-foot` 처럼 좁은 데 | |
| `.btn.toggle.on` | 켜짐/꺼짐 | |

### 세그먼트 `.seg` / `.seg-b.active`

**서로 배타적인 선택**에만 쓴다 (포맷, 모드, 비율). 동작 버튼을 여기 넣지 않는다.

### 설정 한 줄 `.row`

```html
<label class="row"><span>가로</span>
  <input type="range" id="w" min="160" max="1280" step="20">
  <output id="wOut">480</output>
</label>
```

- 첫 `<span>` 이 라벨이다 (`min-width:52px`, `--dim` 색).
- 슬라이더는 `<output>` 과 짝이다. 값이 안 보이는 슬라이더를 두지 않는다.
- 설명은 `.row` 안에 넣지 말고 그룹 마지막에 `.hint` 로 한 번만.

### 그룹 `.grp` / `.grp-title`

`.grp-title` 은 짧은 명사구다 (`얼굴 검출`, `포맷 · 품질`). 문장으로 쓰지 않는다.
CSS 가 대문자로 만드니 영어를 직접 대문자로 적지 않는다.

### 상태 알림 — 세 가지뿐

| 것 | 언제 | 어떻게 |
|---|---|---|
| `toast(msg, kind)` | 끝났다 / 실패했다 / 알아둬라 | 3.2초 뒤 사라짐. `ok` `err` `warn` |
| `busy(on, text)` | 화면 전체를 막아야 하는 긴 작업 | `#busy` 덮개 + `.spin` |
| `progress(i, n, label)` | 여러 개 중 몇 번째 | `#bottombar` 의 `#progressWrap` |

**`alert()` / `confirm()` 을 쓰지 않는다.** 브라우저 기본 대화상자는 디자인 밖이다.
되돌릴 수 없는 동작은 버튼을 `.btn.danger` 로 두고 토스트로 결과를 알린다.

## 6. 한국어 · 영어

문자열은 **`js/i18n.js` 한 곳에만** 둔다. HTML 에는 `data-i18n` 키만 적는다.

```html
<span data-i18n="queue.title"></span>
<button class="btn primary" data-i18n="queue.pick"></button>
```

```js
t('msg.zipDone', { n: 3 })   // "ZIP 저장 완료 (3개)"
```

- 키는 `영역.이름` 꼴이다 (`queue.title`, `face.conf`, `msg.zipDone`).
- 값 안의 `{n}` 은 `t()` 가 채운다. 문자열을 코드에서 이어붙이지 않는다.
- `ko` 와 `en` 두 벌을 같은 파일에 나란히 둔다. `en` 이 비어 있으면 `ko` 로 떨어지므로
  번역이 덜 돼도 화면이 깨지지 않는다.
- 언어 설정은 `localStorage` 의 `language` 키를 자매 도구가 같이 쓴다.

`data-i18n` 이 채우는 곳:

| 속성 | HTML |
|---|---|
| 본문 글자 | `data-i18n="key"` |
| `title` | `data-i18n-title="key"` |
| `placeholder` | `data-i18n-ph="key"` |

## 7. 개인정보 문구는 화면에 늘 보인다

`#topbar` 오른쪽 `.privacy` 알약은 **모든 도구에 반드시 있다.** 닫을 수는 있지만
기본은 켜져 있다. 문구는 그 도구가 실제로 지키는 것만 적는다.

`localStorage` 에는 **설정값만** 넣는다. 사용자 파일(사진·영상)은 어떤 형태로도
저장하지 않는다. 새로고침하면 작업물은 사라지는 것이 맞다.

## 8. 확인된 구현 (clip-box 가 base.css 위에 더한 것)

같은 자리에 같은 부품을 쓰되, 도구마다 화면 하나가 더 붙을 수 있다.
clip-box 는 `#stagePane` 밑에 **타임라인**(`#stageFoot`)을 더했다.
다음 도구가 같은 것을 원하면 그때 `base.css` 로 올린다.

| clip-box 가 더한 것 | 어디 |
|---|---|
| `#stageFoot` (타임라인 + 구간 정보) | `#stagePane` 맨 아래, `flex:none` |
| `#cropBar` (비율 세그먼트) | `#stageWrap` 바로 아래 |
| `.presets` / `.pbtn` (프리셋 카드) | `.grp` 안 |
| `.res` (결과 카드) | 결과 탭 |
| `#busyBody` (덮개 안 진행률) | `#busy` 안 |

## 9. 자동 시험

두 도구 모두 헤드리스 Chromium 으로 실제 화면을 눌러 보는 시험을 둔다.
최소한 이 여섯 가지는 확인한다.

1. 콘솔 오류 0개
2. 외부 요청 목록 (도구가 약속한 것과 맞는지)
3. 파일 넣기 → 결과 내려받기까지 실제 클릭
4. 취소/실패 뒤에 다시 되는지
5. 한 → 영 전환 뒤에도 화면이 안 깨지는지
6. 빈 상태 · 작업 중 · 결과 있음 세 장면 스크린샷

## 10. 지금 두 도구가 다른 점 (알고 다른 것)

| | snap-box | clip-box | 왜 |
|---|---|---|---|
| 스크립트 | classic + `window.SnapLab` 네임스페이스 | ES modules | `@ffmpeg/ffmpeg` 가 ESM 이고 module worker 를 띄운다 |
| `file://` | 열린다 (자동 검출만 빠짐) | 안 된다 | wasm + module worker 는 http 오리진이 필요하다 |
| 외부 요청 | CDN 라이브러리 + MediaPipe 모델 | **0개** (전부 동봉) | clip-box 는 셀프호스팅으로 갔다 |

앞으로 만드는 도구는 **clip-box 쪽(전부 동봉, 외부 요청 0)** 을 기본으로 한다.
CDN 은 도구가 못 쓰게 되는 원인이 되고, 개인정보 문구와도 어긋나 보인다.

snap-box 를 손볼 일이 생기면 그때 `css/style.css` 를 `base.css` + `style.css` 로
쪼개고, CDN 라이브러리도 `vendor/` 로 내리는 것을 같이 하면 된다.
(지금 snap-box 의 `css/style.css` 와 이 저장소의 `css/base.css` 는 값이 같으므로
쪼개기만 하면 화면은 하나도 바뀌지 않는다.)
